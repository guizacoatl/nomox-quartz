# Article 5 - Data to be transmitted to the CTP for bonds

## 1.
With regard to core market data for a given bond, data contributors shall transmit to the data centre of the CTP, by reference to each transaction, the details set out in Table 6 of Annex II that are flagged as ‘input’ or ‘both’ in the last column of Table 6.
## 2.
With regard to regulatory data, data contributors shall transmit to the data centre of the CTP, by reference to each financial instrument, the details set out in Table 2 of Annex II that are flagged as ‘both’ in the last column of Table 2.
## 3.
With regard to regulatory data, data contributors shall transmit to the data centre of the CTP, by reference to each trading system, the details set out in Table 3 of Annex II that are flagged as ‘both’ in the last column of Table 3.
