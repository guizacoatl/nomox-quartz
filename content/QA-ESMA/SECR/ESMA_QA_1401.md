## Question

**Submission Date:** 28 May 2020

(a) How should the residual value of a leased asset be determined for these fields?

(b) How should the field ‘Securitised Residual Value’ (AUTL63 and LESL30) be completed if the residual value has not been securitised?

---

## ESMA Answer

**Answer Date:** 28-05-2020

[ESMA 33-128-563 Securitisation Q&A, Q&A 5.7.2]
(a) For the purposes of these fields, the ‘residual value’ of a leased asset is to be determined in accordance with the applicable accounting framework.
(b) If the residual value has not been securitised, then ND5 should entered into this field.
