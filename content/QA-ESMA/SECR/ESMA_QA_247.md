## Question

**Submission Date:** 12 May 2021

For the field NACE Industry Code (LESL15) we are using the information from our data supplier “Creditreform”. They provide us with the “WZ 2008-Code”. Since our system picks the code with the highest rank, in some cases the LESL15 field contains the value that is too short (e.g. G45.1). According to specification the NACE Code should be reported in full, including the 2 points  and it should be part of the official list. The case G45.1 is a part of official list, but unfortunately it does not fulfil the format criteria as the last dot and number are missing, and in itself it is just 5 characters long. For such cases we tried to add a dot-zero at the end to : G45.1.0 , but the value with (.0) is not in the official list and this format was rejected with the error "NACE Industry Code (LESL15) reports an invalid NACE code".
Can you please clarify what is the proper way of showing/mapping values like this one?
